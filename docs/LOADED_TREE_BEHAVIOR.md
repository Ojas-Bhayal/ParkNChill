# Loading and Applying a Saved Decision Tree

ParkNChill separates three actions:

1. **Load Dataset** reads labels, slot geometry, feature records, provenance and partition assignments. It does not train or modify an active tree.
2. **Load Saved Decision Tree** activates an existing compatible model. It does not rerun image analysis, change the selected occupancy mode, or overwrite the current detector statuses/overlays.
3. **Run Tree Separately** evaluates the active compatible 10-feature tree against the feature vectors already extracted for the current image. Results appear in the `Loaded Tree Prediction` table column and the selected-slot detail panel. This action does not change `Current Status`, detector suggestions, occupancy totals, or image overlays.

A new `Detect and Analyse` run invalidates separately applied predictions because its features or detections may have changed. The user can then click `Run Tree Separately` again.

The analysis-mode dropdown remains available for users who deliberately want the primary `Current Status` to be generated by Vehicle Detection, Feature Decision Tree, or Comparison Mode. Changing that mode triggers a new analysis; it is distinct from loading a model or running the tree in a separate column.
